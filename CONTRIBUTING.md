# Contributing to BitPod

BitPod is in pre-Alpha and is not accepting outside code or content
contributions yet.

Please do not open unsolicited pull requests. The team is still defining the
public product boundary and does not have a maintained intake or review process
for outside contributions. We will update this file when that changes.

For a security concern, do not use a public issue. Follow
[SECURITY.md](SECURITY.md) instead.
