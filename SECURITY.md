# Security Policy

## Pre-Alpha status

BitPod does not have a supported public release yet. This repository and the
public GitHub organization are pre-Alpha surfaces.

## Report a security concern privately

Do not open a public issue for a suspected vulnerability or other sensitive
security concern. Email [cj@bitpod.app](mailto:cj@bitpod.app) with the subject
line `[Security] BitPod report`.

Please include:

- the affected public URL or repository
- a concise description of the concern and its potential impact
- safe reproduction steps, if available
- a way to contact you for follow-up

Do not send passwords, access tokens, private keys, or unrelated personal data.
The mailbox is monitored, but BitPod does not promise a response-time SLA during
pre-Alpha.
